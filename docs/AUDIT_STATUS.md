### 2.4. Админка (`/admin`)

### 2.5. Сравнение цен с конкурентами (price-compare)

| Функция | Детали |
|---------|--------|
| 3 конкурента (топ) | OpticStore, ProfOptica, Optics-Pro |
| Привязка URL | Товар ↔ URL карточки у конкурента (до 3) |
| Парсер цены | Server-side fetch HTML → JSON-LD / meta / грн / ₴ |
| Тест URL без сохранения | Кнопка «Тест парсера» в админке |
| Синхронизация | Одна ссылка / все / cron `0 6 * * *` → `/api/admin/price-sync` |
| UI на витрине | Бейдж на карточке + popover-таблица |
| UI на PDP | Секция «Ціна на ринку» |
| Показ не только «мы дешевле» | ✅ Дешевле (зелёный) / дороже (оранжевый) / ≈ рынок |
| Данные | `last_price`, `last_checked_at`, `last_error`, stale-флаг |

**Рабочий процесс (зафиксировано как целевой / реализованный):**

1. Клиент **добавляет товар** в админке.  
2. **Связывает** товар с конкурентами (URL карточек).  
3. Парсер **снимает/обновляет цены** (кнопка или daily cron).  
4. **Посетитель** на сайте видит сравнение.

**Не входит в «автомат»:** поиск «есть ли эта модель на 3 сайтах» без заранее заданного URL.

## 3. Частично / с оговорками (⚠️)

| Тема | Что есть | Ограничение |
|------|----------|-------------|
| Покрытие price-compare | Часть SKU с реальными URL и live-ценами | Не весь каталог (28+); только привязанные ссылки |
| Парсер HTML | Работает на типичных OpenCart/schema страницах 3-х сайтов | Не 100% страниц (CAPTCHA, JS-only цена, 404) → `last_error` |
| Admin auth | Cookie + env password | Не полноценный IAM / 2FA / audit log |
| Telegram / НП | Код готов | Зависит от env на Vercel |
| Контент blog/about | Страницы есть | Контент может быть демо/заглушкой |
| Юридические тексты | Delivery / warranty / contacts | Нет полного пакета оферты, privacy, возврата (как юр. пакет) |
| Секреты prod | Env на Vercel | Рекомендуется ротация ключей после передачи / демо |
| Domain | Vercel subdomain | Кастомный домен — ops, не feature-код |

## 4. Не реализовано (❌)

| Тема | Комментарий |
|------|-------------|
| **Онлайн-оплата** | Нет LiqPay / Fondy / WayForPay / Stripe; заказ = заявка + (опц.) связь |
| **Авто-матчинг товара у конкурентов** | Нет «добавил модель → нашли на 3 сайтах сами» |
| **Полный ERP / 1С** | Нет двусторонней синхронизации склада |
| **Личный кабинет покупателя** | Нет регистрации / истории заказов клиента |
| **Отзывы / рейтинг live** | Поля/UI могут быть демо; нет модерации UGC |
| **Email-рассылки / CRM** | Нет |
| **Мобильное приложение** | Нет |
| **Мультивалюта** | UAH |
| **Складской учёт с резервом** | Stock в БД при заказе; нет сложного reserve/hold |
| **A/B, аналитика ecom** | Не как продуктовый модуль (можно GTM снаружи) |
| **PCI / compliance-пакет** | Не применимо без платёжного шлюза |

## 6. Модель ответственности (кто что делает)

| Роль | Действие |
|------|----------|
| **Клиент / менеджер** | Добавляет товар; привязывает URL конкурентов; правит цены/stock |
| **Система** | Парсит цены по URL; daily sync; показывает сравнение посетителю; считает заказ из БД |
| **Разработка (не сделано)** | Платежи, автопоиск моделей, юр. пакет, ЛК, усиление auth |

## 7. Вердикт одной фразой

> **E-commerce витрина + админка + заказы (серверные цены) + Nova Poshta + Telegram + сравнение цен с 3 конкурентами по ручным URL и автопарсеру — реализованы.  
> Онлайн-оплата, автопоиск моделей у конкурентов и полный юридический/ops-пакет — не реализованы.**
